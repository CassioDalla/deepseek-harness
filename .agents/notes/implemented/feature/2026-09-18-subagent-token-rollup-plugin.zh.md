# Agent Note: 子代理 token 汇总作为可加性客户端插件

Status: implemented

[English](2026-09-18-subagent-token-rollup-plugin.md) | 中文

## 问题

会话自身的 `tokenUsage` 投影回答的是该会话计费了多少，而不是整棵会话树计费了多少：每个子代理都运行在自己的会话中，拥有自己的持久日志。因此输入框下的数据库 pill 会把一个做了委派的会话，恰好低估它所委派的那部分工作量，而会话头部的谱系树其实已经展示了每个子代理自身的数字。

## 决定

汇总以独立客户端插件 `@deepseek-ai/dsh-client-ui-subagent-tokens` 的形式发布，向 ui-conversation 声明的 `conversation.composer.dock` 列表贡献一个可加性条目。`ui-chat` 保持不变：它的统计 pill 继续报告会话自身的数字，而从 `packages/bundle/web-app/cordis.patch.yml` 删除本插件那一行即可移除该界面。这是对[输入框下的会话统计](2026-09-07-composer-session-stats-pills.zh.md)的细化，后者拥有该 dock 的双 pill 切分与共享的 stat-dialog 皮肤；两者都按该 note 交付的形态保留。

pill 报告子代理的合计计费 token 及其会话数量，并且只在合计非零后渲染——这与 ui-chat 自身 pill 的活动门槛一致，因此子代理尚未计费的会话只保留一个读数，而不是多出一个空读数。它的弹层对齐四个数字——会话自身总量、子代理合计、各自的未缓存输入、缓存读取、缓存写入与输出分桶，以及收尾的 `合计（含子代理）` 行。折叠从每条 `origin: 'subagent'` 摘要出发沿 `parentId` 上溯，前提是当前行本身是子代理；遇到缺失或非子代理的祖先即停止，并保留 seen 集合，使损坏的父指针环能够终止。用量投影尚未到达的子代理仍计入会话数量，但不加 token。

插件只声明 `slots` 与 `locale` 两个服务，且不携带注入面：`useSessions` 提供全局摘要表，`sessionId` 作为折叠的根，`useProjection('tokenUsage')` 提供会话自身的分桶，全部来自框架标准席位。缓存命中率仍留在 ui-chat 的 pill 上，因为子代理可能走其他路由，用它们的提示词聚合出的命中率描述不了任何真实请求。

## 备选方案

**把 ui-chat 的 pill 标题改成会话树总量。** 该能力最初的实现就在 `StatsPills` 内部，读数因此正确，但只能通过修改核心组件及其弹层标记来移除。一个必须打补丁才能装饰目标包的插件不是插件。

**在 ui-chat 中声明扩展点，用于详情行与可加的头条增量。** 这能保留最初的精确读数，但仍然要修改 `ui-chat`，并引入只有一个消费者的接缝。composer dock 本身已经是 list slot，可加性 pill 完全不需要改动核心。

**让 pill 的标题显示会话树总量。** 相邻的 pill 已经给出会话自身数字，第三个数字是二者之和，只会重复读者已经看到的内容，并掩盖只有本插件才知道的增量。

**通过 `ctx.uiSession.provide()` 由 ui-chat 提供汇总钩子。** 组件无法在不依赖插件的前提下消费插件声明的成员，而把单个条目的私有数据做成全局标准属性，正是客户端规则所拒绝的做法。

**在 Host 侧以投影计算汇总。** 浏览器已经持有全部子代理摘要，投影只会为客户端已有的数据新增一份 wire 约定与一次宿主计算。

## 后果

- 做了委派的会话会显示两个 pill：ui-chat 的自身数字与本插件的子代理数字。会话树总量出现在弹层中，而不是头条。
- 子代理读数是所查看会话创建过的全部子代理的累计值，而非按轮次；持久且可继续的子代理没有可显示的按轮次归因。
- 随附的 Web bundle 启用该行，因此界面默认开启，删除该行即可关闭。
- 没有任何模型可见的变化：不涉及会话事件、投影、wire 约定或提示词文本，因此录制的会话快照与 SDK 投影不受影响。
- 那些委派给休眠子代理（其会话未计费任何 token）的已录制 Web 场景保留其录制的 aria golden，因为活动门槛使 pill 在那里保持未挂载状态。
- 包的 `src/client/*` 处于逐文件覆盖率门槛之内；node 半边是惰性的 loader 占位，由 browser-plugin 用例覆盖。
